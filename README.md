# Лендинг BuyNow System — установка и деплой

Одностраничник без сборки: весь код в `index.html`. Внешние зависимости только шрифт Onest (Google Fonts) и иконки Phosphor (unpkg). Ничего собирать и устанавливать не нужно.

---

## 1. Что заменить перед публикацией

Всё, что нужно править, собрано в трёх местах.

| Что | Где | Как |
|---|---|---|
| Ссылка на Telegram | `<body data-tg="https://t.me/YOUR_USERNAME">` | Один раз, подставляется во все кнопки автоматически |
| Видео (YouTube) | `<div class="vsl__frame" id="vsl" data-video="">` | Впишите ID ролика: `data-video="dQw4w9WgXcQ"` |
| Видео (другой хостинг) | тот же блок | `data-video-src="https://player.vimeo.com/video/123456"` |
| Обложка видео | тот же блок | `data-poster="poster.jpg"`, иначе берётся превью YouTube |
| Фото эксперта | `photo.jpg` рядом с `index.html` | Уже вставлено. Чтобы заменить, положите новый файл под тем же именем, квадратный кадр от 800×800 |
| Цифры и факты | подсвеченные `[в скобках]` | Найдите по тексту `class="fill"` и впишите реальные значения |
| Домен в мета-тегах | `<link rel="canonical">` и блок Open Graph | Замените `https://example.com/` на свой домен |
| Картинка для соцсетей | `og:image` | Положите `og.jpg` 1200×630 рядом с `index.html` |
| Логотип и фавикон | шапка страницы и `<link rel="icon">` | Уже встроены, менять не нужно. Отдельные файлы: `logo-mark.svg`, `favicon.svg` |
| ID Яндекс.Метрики | в скрипте: `var YM_ID = null;` | Впишите номер счётчика, например `var YM_ID = 12345678;` |

Плейсхолдеры в тексте подсвечены зелёным с пунктиром. Пока они видны на странице, лендинг не готов к трафику.

## 2. Публикация на GitHub Pages

### Через веб-интерфейс (проще)

1. Создайте новый репозиторий, например `baynov-landing`. Публичный.
2. **Add file → Upload files**, перетащите `index.html` (и `og.jpg`, `photo.jpg`, если они есть). Commit.
3. **Settings → Pages**.
4. В *Source* выберите **Deploy from a branch**, ветка `main`, папка `/ (root)`. Save.
5. Через 1–2 минуты сайт доступен по адресу `https://ВАШ_ЛОГИН.github.io/baynov-landing/`.

### Через командную строку

```bash
cd путь/к/папке/landing-baynov
git init
git add .
git commit -m "landing v1"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/baynov-landing.git
git push -u origin main
```

Дальше пункты 3–5 из списка выше.

## 3. Свой домен

1. В корень репозитория добавьте файл с именем `CNAME` (без расширения). Внутри одна строка:

   ```
   baynov.ru
   ```

   Либо укажите домен в **Settings → Pages → Custom domain**, GitHub создаст файл сам.

2. У регистратора домена пропишите DNS-записи.

   **Для домена без www (apex, `baynov.ru`)** — четыре A-записи:

   ```
   A   @   185.199.108.153
   A   @   185.199.109.153
   A   @   185.199.110.153
   A   @   185.199.111.153
   ```

   **Для поддомена (`www.baynov.ru` или `go.baynov.ru`)** — одна CNAME-запись:

   ```
   CNAME   www   ВАШ_ЛОГИН.github.io.
   ```

3. Вернитесь в **Settings → Pages**, дождитесь проверки домена и включите **Enforce HTTPS** (галочка появляется после выпуска сертификата, обычно 10–30 минут).

DNS обновляется до нескольких часов. Проверьте актуальность IP-адресов в документации GitHub Pages перед настройкой, они меняются редко, но меняются.

## 4. Аналитика

Счётчики вставляются в `<head>`, сразу перед `</head>`.

**Яндекс.Метрика:** скопируйте код счётчика из интерфейса Метрики. После этого в скрипте внизу страницы замените `var YM_ID = null;` на номер счётчика. Тогда клики по кнопкам будут отправляться как цели.

**Google Analytics 4:** вставьте стандартный сниппет `gtag.js`. Событие `generate_lead` отправляется автоматически.

Цели, которые уже размечены в коде:

| Идентификатор | Событие |
|---|---|
| `cta_nav` | кнопка в шапке |
| `cta_hero` | кнопка в первом экране |
| `cta_final` | кнопка в финальном блоке |
| `cta_sticky` | липкая кнопка на телефоне |
| `cta_footer` | ссылка в подвале |
| `video_play` | запуск видео |

В Метрике создайте цели типа **JavaScript-событие** с этими идентификаторами.

**UTM-метки** из адреса страницы автоматически переносятся в ссылку Telegram через параметр `?start=`. Это работает для чат-бота. Если ссылка ведёт на личный аккаунт, Telegram параметр проигнорирует, источник придётся спрашивать в переписке.

## 5. Что изменилось относительно старого сайта (91smn.weblium.site)

Страница собрана из фактов старого сайта, но с другой целью: не «оставьте email и получите доступ к видео про доходность», а «запишитесь на консультацию».

**Перенесено:** блок «Для кого», темы серии видео (стали повесткой консультации), все регалии Петра Алексеевича, цитата про безопасность процессов и контроль, аргументы безопасности (регулирование FCA / FINMA / ASIC / MFSA, сегрегированные счета, компенсационная схема, «Защита капитала» на софтверном уровне, отсутствие конфликта интересов, независимый мониторинг Myfxbook и FXBlue, история с 2014 года), дисклеймер о рисках.

**Убрано осознанно:**

- Все обещания доходности: «15...30% годовых», «превышающий депозит в 10...30 раз», «более 40% годовых», «50...100% годовых». Они противоречат позиционированию «эксперт по безопасности» и создают юридический риск.
- Витрина решений (Buynow-System, INFINITY 2.0, HARMONY 3.0, Harmony Medium, INNOVATIVE) со ссылками на мониторинг.
- Пошаговая инструкция открытия счёта у Equiti, верификация, LPOA, реинвестиции. Это воронка доверительного управления, а не консультации. При необходимости обсуждается на встрече.
- Форма сбора email. Единственное целевое действие теперь Telegram.

**Требует вашего решения:** на старом сайте в блоке преимуществ написано «все счета клиентов застрахованы до 1 000 000 USD», а в подвале «до 100 000 долларов». Цифры противоречат друг другу, поэтому на новой странице сумма заменена плейсхолдером. Впишите корректное значение и юрисдикцию либо оставьте формулировку без числа.

## 6. Что ещё нужно от вас

- Продающее видео, 16:9, желательно до 6 минут.
- Картинка для соцсетей 1200×630 (`og.jpg`).
- Сумма страхового покрытия и юрисдикция для блока «Компенсационная схема».
- Порог по сумме капитала для FAQ либо решение, что порога нет.
- Решение по юридическому статусу: самозанятый, ИП или иначе. Это влияет на текст дисклеймера в подвале и на то, как принимать оплату.

Стоимость консультации указана: 200 евро за час. Она стоит в трёх местах: мета-описание страницы, блок цены перед финальной кнопкой и ответ в FAQ. При изменении цены поправьте все три.

## 7. Логотип

Знак: две скобки кода, образующие щит. Защита капитала и защита софта в одном символе. Акцент `#0E6E5B`, шрифт логотипа Onest 800 для «BuyNow» и Onest 500 для «System».

Файлы в этой папке:

| Файл | Для чего |
|---|---|
| `logo-mark.svg` | Только знак, акцентный цвет, для документов и презентаций |
| `favicon.svg` | Знак в белом на акцентной плашке, скруглённый квадрат |

В самой странице логотип собран вёрсткой (SVG плюс текст), поэтому масштабируется без потерь и красится через переменную `--accent`. Фавикон встроен прямо в `<link rel="icon">` как data-URI, отдельный файл заливать не обязательно.

Для писем, презентаций и печати горизонтальный логотип удобнее выгрузить картинкой из макета логотипа: там есть кнопка экспорта PNG. Ссылка на макет лежит в переписке, там же четыре варианта знака, монохромные версии и правила использования.

Если понадобится `apple-touch-icon`, сделайте PNG 180×180 из `favicon.svg` и положите рядом с `index.html`, добавив строку `<link rel="apple-touch-icon" href="apple-touch-icon.png">`.
